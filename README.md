# Currency Converter

A Python-based Currency Converter using live exchange rates.

## Features
- Live currency exchange rates
- INR to USD
- USD to INR
- INR to EUR
- EUR to INR
- INR to GBP
- GBP to INR
- Input validation
- Error handling

## Technologies
- Python
- Requests Library
- ExchangeRate API

## Installation
pip install -r requirements.txt

## Run
python main.py
